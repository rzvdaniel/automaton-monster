# Automaton Monster store

Showcase apps, games and experiments for [Automaton](https://automaton.monster), kept apart from the essential apps of the official catalog ([automaton-apps](https://github.com/rzvdaniel/automaton-apps)).

[Automaton source](https://github.com/rzvdaniel/automaton) · [App documentation](https://automaton.monster/docs/) · [Automaton App Store](https://store.automaton.monster/)

## Apps

| App | Source |
| --- | --- |
| GoatCounter — privacy-friendly web analytics, built from a pinned upstream release (EUPL-1.2) | [analytics/goatcounter](analytics/goatcounter/) |
| linkding — a bookmark manager, packaged from the upstream image | [productivity/linkding](productivity/linkding/) |
| Harbour Wallpaper — a living harbour island for your desktop that reacts to clicks | [wallpapers/harbour](wallpapers/harbour/) |
| Untranslatable — a multiplayer word-bluffing game | [games/untranslatable](games/untranslatable/) |
| Head Counter — tracks server and CLI release downloads, excluding our own checks | [tools/head-counter](tools/head-counter/) |

GoatCounter, linkding, Harbour and Head Counter used to be in the official catalog. Their entries carry `movedFrom`, so a server that installed one of them there shows it as installed and updates it from here.

## Use this store on your server

A system administrator opens **Apps → Catalog → Catalog sources** in Studio and adds `https://github.com/rzvdaniel/automaton-monster`, or runs `automaton catalog sources add https://github.com/rzvdaniel/automaton-monster`. The store is off by default.

## Catalog

The format, CI and review flow are those of automaton-apps. `catalog.json` in the root of `main` is generated by `python tools/generate_catalog.py` from `catalog-apps.json` and each app's `automaton.json`. After a merge to `main`, CI regenerates it (each app pinned to the last commit that changed its folder) and, when it changed, merges a `catalog-bot` pull request. You do not edit it by hand. See the [apps repository documentation](https://automaton.monster/docs/apps-repository).

## Contributing

Keep changes within the relevant app folder, document new setup requirements, run that app's checks, and never commit credentials. Agents follow [AGENTS.md](AGENTS.md).
